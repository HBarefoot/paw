## How to sign

Signing is a one-time step per GitHub account.

On your first pull request, the **CLA Assistant** bot will leave a comment asking you to sign. Reply on that PR with:

> I have read the CLA Document and I hereby sign the CLA

Your signature is recorded. Subsequent PRs from the same GitHub account skip the prompt automatically. If you ever need to re-sign (e.g. the CLA text materially changes), comment `recheck` on the PR and the bot will refresh the check.

If you prefer to sign explicitly in-line, you may instead add the signature block below to your pull request description:

```
I have read and agree to the Paw Contributor License Agreement.

Contributor name:
GitHub username:
Date:
```

## Why we have a CLA

Paw is, and will remain, open source under the **Apache License 2.0** (see [`LICENSE`](LICENSE)). The CLA exists for two reasons:

1. **Clean copyright + relicensing rights.** If contributors retain copyright with no license grant, the project can't be relicensed later — even to another license — without contacting every past contributor. The CLA grants the relicensing right up front so Barefoot Digital keeps long-term flexibility to evolve the project's licensing and business model without orphaning past contributors' work.
2. **Acquirer-clean codebase.** If Paw is ever adopted by a larger entity, the acquirer needs a clean chain of IP rights. The CLA pre-empts the diligence pain that otherwise stalls these conversations.

**The CLA is permissive — it does not prevent you from using your own contribution however you like.** You still own your work. You're granting a license to Henry Barefoot / Barefoot Digital, not transferring copyright.
